# 🐛 PestSense AI

PestSense AI is a lightweight, real-time pest detection system built using YOLOv5 Nano and Streamlit. It performs on-device inference without relying on cloud APIs, ensuring low latency and privacy.

## 🚀 Features

* On-device AI inference
* Lightweight model (<50MB)
* Real-time detection
* Image upload interface
* Low latency (<100ms)

## 🧠 Tech Stack

* YOLOv5 Nano
* PyTorch
* OpenCV
* Streamlit

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ⚠️ Note

This system uses a pretrained model for demonstration and can be fine-tuned for real pest datasets.
